# Hardball Politics — «Политика без поблажек»

Модификация для **Tropico 6**, которая делает выборы реальной проверкой качества управления, а не формальностью, проходящейся одной предвыборной речью.

## Что меняет мод

### Предвыборная речь
- Прямой бонус поддержки от **восхваления фракции** урезан до **~30%** от исходного.
- Немедленные бонусы **поддержки избирателей** внутри системы речи — до **~30%**.
- Немедленный эффект **политических обещаний** — до **~28%** (цель — 25–30%).
- Многолетнее плохое управление больше нельзя компенсировать одной речью.

### Требования фракций и политические конфликты
- Шанс **одновременных требований двух фракций** +25%.
- Период перезарядки **ультиматумов фракций** — 80% от исходного (~25% чаще); сам механизм перезарядки полностью сохранён.
- Срок исполнения ультиматума и время жизни неисполненных предложений сокращены до 80%.

### Накопление недовольства и эскалация
- Игнорируемая проблема достигает максимума за **70%** исходного срока: длительный кризис опаснее кратковременного.
- Недовольные и партизаны копят **очки восстания на 25% быстрее** — затяжной кризис раньше доходит до восстания.
- Протесты начинаются при чуть более высоком пороге счастья (×1.1) — предупреждение приходит раньше.
- Пороги восстаний НЕ меняются: масштаб остаётся ограниченным, армия не ослабляется.

### Общая политическая реактивность
- Рост и падение поддержки фракций ×1.2: политическая ситуация быстрее реагирует на ваши решения.

## Что мод НЕ меняет

- Экономику, производство, зарплаты, цены, торговлю.
- Боевые характеристики юнитов и характеристики военных зданий.
- Дипломатию, отношения с супердержавами и их требования (включая речь с обвинением иностранной державы).
- Периодичность выборов и стандартный Game Over при проигрыше выборов.

Полный список подтверждённых параметров и источников: [docs/POLITICS_ASSETS_MAP_RU.md](docs/POLITICS_ASSETS_MAP_RU.md).

## Как это устроено технически

Мод работает по подтверждённому сообществом механизму переопределения ассетов Unreal Engine 4 (Tropico 6 построена на UE4):

1. Из `.pak`-файлов **вашей** копии игры извлекаются политические ассеты (`BP_T6SingletonData`, ультиматумы фракций и др.).
2. В них точечно меняются значения по рецепту `recipe/hardball_recipe.json` (каждая правка проверяется по исходному диапазону и попадает в журнал).
3. Изменённые ассеты упаковываются в `z_HardballPolitics.pak`, который игра загружает поверх оригинала.

Оригинальные файлы игры **не изменяются**. Удаление `.pak` полностью возвращает стандартное поведение.

## Установка без Python — один файл (Windows)

Ничего устанавливать не нужно: батник использует встроенный Windows PowerShell, сам скачивает инструменты и собирает мод из файлов вашей копии игры.

1. Скачайте один файл: **<https://github.com/bedcarto-wq/Tropico/raw/main/HardballPolitics.bat>**
2. Положите его в любую папку (например, на рабочий стол) и запустите двойным щелчком.
3. Выберите пункт **1** — «Установить мод». Программа сама найдёт Tropico 6 (или попросит указать путь), скачает UAssetGUI и UnrealPak, извлечёт политические ассеты, применит рецепт правок, соберёт и установит `z_HardballPolitics.pak`.
4. Запустите игру. Отключить мод — пункт 2 (или удалить `.pak` из папки `Tropico6\Content\Paks`).

Примечания:

- SmartScreen может предупредить о запуске скачанного файла — «Подробнее → Выполнить в любом случае».
- Интернет нужен только при первом запуске для загрузки инструментов (~15 МБ).
- Рабочие файлы создаются рядом с батником (папки `work`, `tools`), файлы игры не изменяются.
- Тот же конвейер в виде читаемого скрипта: `hardball_core.ps1` (можно запускать в PowerShell без батника).

## Вариант с Python (для продвинутых)

Требуется: Windows, установленная Tropico 6, Python 3.8+ (галочка «Add to PATH» при установке), интернет для первичной загрузки инструментов.

```bat
git clone https://github.com/bedcarto-wq/Tropico.git
cd Tropico
python hardball.py setup
python hardball.py extract
python hardball.py patch
python hardball.py package
python hardball.py install
```

Подробная инструкция для пользователей без опыта моддинга: [docs/INSTALL_RU.md](docs/INSTALL_RU.md).
Как проверить работу мода в игре: [docs/INGAME_TESTS_RU.md](docs/INGAME_TESTS_RU.md).

## Отключение

```bat
python hardball.py uninstall
```

Или вручную удалите `<игра>\Tropico6\Content\Paks\z_HardballPolitics.pak`.

## Известные ограничения

Полный честный список: [docs/LIMITATIONS_RU.md](docs/LIMITATIONS_RU.md). Ключевое:

- Финальная сборка `.pak` выполняется на вашем компьютере (Windows): она требует извлечения ассетов из **вашей** копии игры — распространение готового бинарного `.pak` с чужими ассетами не допускает лицензия игры, а чужие версии ассетов приводят к вылетам.
- Изменены параметры, существование которых подтверждено в реальных ассетах игры. Часть требований ТЗ (например, накопительный эффект повторных репрессий) опирается на внутреннюю логику движка, недоступную для изменения через переопределение ассетов, и оставлена в оригинале — это отражено в ограничениях, без имитации реализации.

## Структура проекта

```
hardball.py                    — CLI: setup/extract/scan/patch/package/install/uninstall
recipe/hardball_recipe.json    — рецепт правок (15 правил, с описаниями на русском)
tests/test_recipe_logic.py     — автономные тесты движка (python tests/test_recipe_logic.py)
docs/                          — установка, проверка в игре, ограничения, карта параметров
```

## Совместимость

- Целевая версия: Tropico 6 v.23 (1290) и актуальные сборки. Инструмент работает с ассетами вашей установленной версии; если сериализация движка в будущем обновлении изменится, достаточно изменить `uasset_engine_version` в `hardball_config.json`.
- Конфликт модов: любые другие моды, переопределяющие `BP_T6SingletonData`, ультиматумы или требования фракций, будут конфликтовать с этим модом (загружается тот, что стоит позже по алфавиту в Paks).
