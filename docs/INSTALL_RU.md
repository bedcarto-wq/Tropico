# Установка мода Hardball Politics (Windows, без опыта моддинга)

## Самый простой способ — один файл, без Python (рекомендуется)

1. Скачайте **один файл**: <https://github.com/bedcarto-wq/Tropico/raw/main/HardballPolitics.bat>
2. Положите его в любую папку (например, на рабочий стол) и запустите **двойным щелчком**.
3. Если Windows SmartScreen покажет синее окно — нажмите **«Подробнее» → «Выполнить в любом случае»** (обычное предупреждение для скачанных файлов).
4. В открывшемся меню выберите **1 — Установить мод (все шаги автоматически)**.
   - Программа сама найдёт Tropico 6 (проверяет Steam, Epic и реестр; если не найдёт — попросит вставить путь к папке игры).
   - При первом запуске скачает инструменты (UAssetGUI, UnrealPak; ~15 МБ) в подпапку `tools`.
   - Извлечёт политические ассеты из `.pak`-файлов вашей копии игры, применит рецепт правок, соберёт и установит `z_HardballPolitics.pak`.
5. Запустите Tropico 6 — мод загрузится автоматически.
6. Отключить мод: снова запустите `HardballPolitics.bat` и выберите **2 — Удалить мод из игры**. Оригинальные файлы игры при этом не затрагивались — удаление полностью возвращает стандартное поведение.

Дополнительные пункты меню: **3** — статус и диагностика, **4** — подробный отчёт обо всех политических параметрах вашей версии игры (файл `work\reports\politics_scan.txt`).

Если что-то пошло не так — сфотографируйте или скопируйте текст из чёрного окна и создайте Issue в репозитории.

## Способ с Python (альтернатива)

Мод собирается на вашем компьютере из файлов вашей копии игры. Это занимает 10–15 минут и выполняется несколькими командами.

## Что понадобится

1. **Windows** с установленной Tropico 6 (Steam или Epic).
2. **Python 3.8 или новее** — скачать с https://www.python.org/downloads/ . При установке обязательно отметьте галочку **«Add python.exe to PATH»**.
3. Интернет — для первичной загрузки инструментов (UAssetGUI, UnrealPak; ~15 МБ).

## Шаг 1. Скачайте проект

Скачайте репозиторий (зелёная кнопка **Code → Download ZIP**) и распакуйте, либо:

```bat
git clone https://github.com/bedcarto-wq/Tropico.git
```

## Шаг 2. Откройте командную строку в папке проекта

В проводнике откройте папку проекта, в адресной строке напишите `cmd` и нажмите Enter.

## Шаг 3. Подготовка

```bat
python hardball.py setup
```

Скрипт создаст рабочие папки, скачает инструменты и попробует сам найти игру.

Если игра не нашлась, укажите путь вручную (папка, где лежит подпапка `Tropico6`):

```bat
python hardball.py set-game "C:\Program Files (x86)\Steam\steamapps\common\Tropico 6"
```

Проверьте готовность: `python hardball.py doctor` — должно быть «готово к работе».

## Шаг 4. Извлечение ассетов игры

```bat
python hardball.py extract
```

Из `.pak`-файлов игры извлекаются только политические ассеты (SingletonData, ультиматумы, требования, эскалации, данные восстаний). Это занимает пару минут. **Оригинальные файлы игры не изменяются.**

## Шаг 5. Применение правок

```bat
python hardball.py patch
```

Утилита читает реальные значения из ваших ассетов, применяет рецепт правок и печатает, что именно изменено. Полный журнал сохраняется в `work/reports/patch_log.json`.

Полезно сначала посмотреть, что вообще есть в политической системе:

```bat
python hardball.py scan
```
— создаёт отчёт по всем числовым политическим параметрам (`work/reports/politics_scan.txt`).

## Шаг 6. Сборка и установка

```bat
python hardball.py package
python hardball.py verify
python hardball.py install
```

- `package` — собирает `z_HardballPolitics.pak`.
- `verify` — проверяет, что все изменённые ассеты попали в пакет.
- `install` — копирует `.pak` в папку игры.

Запустите Tropico 6 — мод загружается автоматически при старте.

## Обновление мода / пересборка

После изменения рецепта или обновления игры повторите шаги 4–6. Если игра обновилась, обязательно выполняйте `extract` заново, чтобы мод базировался на актуальных ассетах.

## Отключение и удаление

```bat
python hardball.py uninstall
```

Игра мгновенно вернётся к стандартному поведению. Чтобы удалить всё: удалите папку проекта и, при желании, `work/`.

## Устранение проблем

| Симптом | Решение |
|---|---|
| `python` не является командой | Переустановите Python с галочкой «Add to PATH» |
| Игра не найдена | `python hardball.py set-game "путь"` |
| `Cannot find drive ... 'D' does not exist` | Скрипт перебирал диски при автопоиске игры; в свежей версии (от 09.10) это исправлено — скачайте `HardballPolitics.bat` заново. Либо запустите пункт 1: скрипт спросит путь вручную |
| `The property 'MaxRecursionDepth' cannot be found` | Баг JSON-движка для старого Windows PowerShell 5.1; исправлен в свежей версии (от 09.10) — скачайте `HardballPolitics.bat` заново |
| Ошибка при extract (magic number) | Ваша версия игры использует новый формат pak — укажите путь к UnrealPak из свежей версии UE4 в `hardball_config.json` (`unrealpak_extract_exe`) |
| Ни одно правило не сработало в patch | Выполните `scan` и пришлите отчёт разработчику мода — структура ассетов вашей версии отличается |
| Мод не влияет на игру | Убедитесь, что `.pak` лежит именно в `Tropico6\Content\Paks`, и что его имя начинается с `z_` |
